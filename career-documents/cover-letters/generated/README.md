# Generated cover letters

FR-007 drafts written by `scripts/run_cover_letter_manual.py`.

Each stem includes:

- `{stem}.md` — submit-ready Markdown (owner review required)
- `{stem}.html` — print-friendly HTML (shared CV print CSS)
- `{stem}.json` — typed `CoverLetter`
- `{stem}.cover_letter_plan.json` — typed `CoverLetterPlan`

Review Markdown and HTML together against the tailored CV for the same role —
they should feel like one professional document suite.

These files are operational artefacts and may be gitignored locally.
